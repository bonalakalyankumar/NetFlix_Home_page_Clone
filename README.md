# 📺 Netflix Home Page Clone

Welcome to the Netflix Home Page Clone! This project replicates the Netflix home screen, showcasing a visually appealing and responsive UI built using **Jetpack Compose**.

---

## 🚀 Features

- **Dynamic UI**: Mimics Netflix's home page with rows of trending, popular, and recommended content.
- **Modern Design**: Implements material design principles with Jetpack Compose.
- **Smooth Animations**: Supports horizontal and vertical scrolling with polished transitions.
- **Content Previews**: Interactive thumbnails with real-time loading effects.
- **Scalable Architecture**: Modular components for easy expansion and maintenance.

---

## 🛠️ Tools & Technologies

- **Kotlin**: Core programming language.
- **Jetpack Compose**: Declarative UI toolkit for building native UIs.
- **MVVM Architecture**: Ensures separation of concerns and clean code structure.
- **Android Studio**: Development environment for building and debugging.

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bonalakalyankumar/NetFlix_Home_page_Clone.git
   cd NetFlix_Home_page_Clone
   ```

2. Open the project in **Android Studio**.

3. Build and run the project on an emulator or physical device.
